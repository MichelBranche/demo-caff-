# Orma

Landing page per Orma, microtorrefazione immaginaria di caffè di specialità in Valle d’Aosta. Il marchio, i lotti e i prezzi sono di fantasia.

## Avvio

```bash
npm install
npm run dev
```

Il sito resta in ascolto su [http://localhost:5173](http://localhost:5173).

## Build

```bash
npm run build
```

La build controlla i tipi TypeScript e produce la cartella `dist`.
